# 경주 발견 → 공식 근거 검토 → 심의

2026-11-18. 이번 실험은 장소 정보를 모은 뒤 실제로 놀 곳을 선택할 수 있는지를 검토한다. 운영시간 정확성과 정보의 집약·선택 가능성은 각각 평가한다. 정보가 있는 사이트의 존재와 사용자가 쉽게 필요한 정보를 찾는지는 다른 문제다.

## 입력의 출처와 한계

외부 작업 공급자가 웹 도구로 공식 페이지를 읽어 근거 묶음을 작성한다. Codex 런타임의 세 advisory 역할은 제공된 근거를 정리·비교·심의한다. 역할 자체의 웹 수집 기능을 검증하는 실험은 아니다.

공개 재현 입력은 [gyeongju-public-baseline-v1.json](gyeongju-public-baseline-v1.json)이다. 개인 제보를 포함한 실제 실행 입력과 세션은 ignored `artifacts/`에만 보관한다. 한 참여자의 경험은 탐색 질문의 근거이며 전체 시장 수요나 경쟁 서비스 부재의 증거가 아니다.

| 후보 | 이번에 확보한 근거 | 검토할 점 |
| --- | --- | --- |
| 동궁과 월지 | 경주시 코스·요금 안내 | 오래된 시간 안내, 혼잡에 따른 입장 제약 |
| 대릉원·천마총 | 경주시 코스·요금 안내 | 공원 무료와 천마총 유료의 구분 |
| 첨성대 | 경주시 코스·요금·포토스팟 | 계절 설명과 현재 개화 상태 구분 |
| 월정교 | 경주시 코스·포토스팟 | 문루와 다리 구분, 징검다리 실제 통행 미확인 |
| 황리단길 | 경주시 코스 | 거리 소개만으로 개별 활동·업체를 선택할 수 있는가 |
| 국립경주박물관 | 경주시 코스와 박물관 관람 안내 | 운영시간 출처 충돌 |

[경주시 코스 글](https://gyeongju.go.kr/tour/page.do?mnu_uid=4722)은 정보 기준을 2023년 2월로 명시한다. [박물관 운영기관 안내](https://gyeongju.museum.go.kr/kor/html/sub01/0101.html)는 2026년 3월 시행 시간으로 3~10월 토요일 20시까지 연장을 안내한다. 코스 글의 연장 시간·기간과 다르다. 수집일이 최신이라고 자료 내용도 최신인 것은 아니다.

[경주시 요금표](https://www.gyeongju.go.kr/tour/page.do?mnu_uid=4838)는 대릉원과 천마총 요금을 구분한다. [포토스팟 페이지](https://search.gyeongju.go.kr/tour/page.do?mnu_uid=4758)는 같은 기관의 자료이므로 독립적인 현장 확인으로 세지 않는다.

시설공단 사이트의 공식 Instagram 링크는 찾았지만 계정 본문을 확보하지 못했다. 실제 SNS 게시물, 인기 지표, 방문 후기는 입력에 없다. 게시물을 만들어 보충하지 않는다. 이번은 단일 시점 근거 묶음이며 주기적 변경 추적·72시간 갱신 검증은 아니다. 사진·본문 재배포 및 자동 수집 조건 검토도 완료하지 않았다.

## 실행 계약

외부 공급자가 심의 역할을 먼저 제출하고 `waiting`을 관찰한다. 검증 역할도 발견 문서를 기다리도록 제출한 뒤 대기를 확인한다. 마지막으로 발견 작업을 제출한다.

```text
심의 대기 → 검증 대기 → 발견 완료·SMS
                          ↓
                     검증 재개·SMS → 심의 재개
```

워커 1개, 역할 3개, 모델 실행 5회, 대기 2회, 재개 2회가 예상된다. 두 문서는 영속 SMS 본문으로 전달한다. 완료 후 메일박스 주소·버전·후보 ID·근거 참조와 실행 카운터를 확인한다. 구조 검증이 사실의 정확성이나 제품 가치 검증을 대신하지 않는다.

모델 턴의 기본 경과시간 제한은 없다. heartbeat는 연결 응답성을, 진행 이벤트는 출력 활동을 보여 준다. 실행 실패를 성공으로 바꾸거나 자동으로 재시도하지 않는다.

```sh
./scripts/go.sh build -o bin/codex-evidence-pipeline ./cmd/codex-evidence-pipeline
mkdir -p artifacts
./bin/codex-evidence-pipeline \
  --evidence experiments/event-search/gyeongju-public-baseline-v1.json \
  --state artifacts/gyeongju-public-run-01 \
  > artifacts/gyeongju-public-report.json \
  2> artifacts/gyeongju-public-monitor.jsonl
```

Codex 로그인·네트워크가 필요하다. `--state`는 존재하지 않는 새 경로여야 한다. 기본은 backend 출력 스키마를 사용한다. `--structured-output=false`는 명시적으로 선택하는 진단 모드이며 실패 뒤 자동으로 전환하지 않는다. 공개 입력으로 재실행하면 개인 제보가 포함된 원 실행과 입력 및 결과가 달라질 수 있다.

검증 역할의 `observedDiscoverySummary`는 실제 발견 SMS의 요약과, 심의 역할의 `observedFinding`은 실제 검증 SMS 첫 판단의 문장과 정확히 대조한다. 이는 전달된 모델 산출물의 반영 검사이며 독립적인 현장 사실 확인은 아니다.

## 실제 실행 결과

첫 실행은 **104.13초, completed=true**로 끝났다. [비식별 지표](gyeongju-pipeline-metrics.json): 역할 3개, 워커·프로세스 각각 1개, 모델 실행 5회, 작업 완료 3개, 대기·재개 각각 2회, lease heartbeat 9회. 두 SMS 주소·버전·후보 집합과 실제 생성 문장 반영 검사를 모두 통과했다. 모델 출력 스키마를 사용했고 기본 모델을 변경하지 않았다. 성공 turn의 마지막 토큰 알림 합계는 입력 50,286, 출력 4,216, 캐시 입력 21,248이다. 전체 청구 비용이나 메모리 절감의 측정값은 아니다.

실제 산출물의 판단은 다음과 같다.

- 동궁과 월지·대릉원/천마총·첨성대·월정교: 일부 근거는 있으나 최신 운영·현장 조건이 미확인인 `partially-supported`.
- 황리단길: 지역 소개만으로 구체적인 활동을 고를 수 없는 `insufficient-for-choice`.
- 박물관: 운영기관의 명시된 최신 시행 자료를 우선하는 `supported-with-source-priority`. 임시휴관과 특별전까지 검증됐다는 의미는 아니다.
- 심의 결론: **request evidence**. 구체적인 활동, 취향·동행 적합성, 총비용, 체류시간, 이동 거리·시간 및 연결 동선을 비교할 근거가 더 필요하다. 장소명과 운영시간만 모아서는 선택 문제를 해결했다고 볼 수 없다.

다음 제품 검증은 실제 선택 사례 하나를 기준으로 비교 자료를 만들고, 필요한 정보를 찾고 장소를 결정할 수 있는지 확인하는 것이다. 세부 활동·가격·소요시간 등 미확인 필드는 빈칸으로 유지하며 실제 경험이나 추가 출처로 보완한다. 이 심의는 사업의 성공·수요를 확정하지 않는다.

`./scripts/check.sh` 통과: 포맷, vet, Go race, Python 및 기존 pi 검사. CLI 테스트는 잘못된 후보 집합·미등록 출처·문서 반영 불일치·근거 크기 제한 등을 확인한다. 원 실행 입력·보고서·감시 로그는 각각 `artifacts/gyeongju-evidence-v1.json`, `artifacts/gyeongju-pipeline-01-report.json`, `artifacts/gyeongju-pipeline-01-monitor.jsonl`에만 보관한다.
