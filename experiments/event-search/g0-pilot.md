# G0 사업 심의 파일럿

실행일: 2026-11-17. 상태: 독립 검토·교차 반론·G0 결정 완료. 외부 조사 미실행.

후속 변경: 사용자가 원래 목적을 명확히 하면서도 범위 선택은 에이전트에게 위임했다. D0의 서울 주말 행사 방향은 여러 대안과 재비교했다. 이전 심의 기록은 보존하되 현재 범위와 새 안건은 [G1 재심 기록](g1-decision.md)을 따른다.

## 실행 경계

실제 모델 기반의 협업 에이전트 3명이 독립 검토하고 주 에이전트가 사업 제안자·의장·기록 담당을 순차 수행한다. role-runtime 실행이 아니며 Codex RPC 어댑터, 영속 역할 복원, SMS, 워커 효율을 검증하지 않는다. 외부 시장 조사·고객 접촉·실제 지출은 수행하지 않는다. 시장성과 수익성은 미확인이다. 아래 기록은 검토 결과를 정리한 산출물이며 세션 원문이 아니다.

## 제안 P0 v1

- 문제 가설: 여러 출처의 이벤트·혜택을 확인하는 사람이 자신에게 유효한 정보를 찾고 조건을 비교하는 데 불편을 겪는다.
- 해결 가설: 정보를 검색하고 원문으로 이동하는 서비스를 제공하면 탐색 부담을 줄일 수 있다.
- 미확정: 고객군, 지역, 정보 범주, 반복 사용 빈도, 지불 의사, 데이터 공급 경로, 수익 모델.
- 대안: 범용 검색, 특정 고객군 전용 알림, 수동 큐레이션, 제공자 대상 정보 관리, 사업 중단. 기존 대안의 실제 효과는 조사하지 않았다.
- 요청: 제품 개발 투자에 앞서 고객 문제와 데이터 공급 가능성을 조사할 가치가 있는지 판단한다.
- 예산: 실제 지출 요청 없음. 조사 인력·모델·데이터·인프라·마케팅 비용의 항목 및 산정 방식부터 검토한다.
- 이번 심의의 완료 기준: 독립 검토 3건, 주요 반론에 대한 수정안, 재검토 조건이 있는 G0 결정 1건.

## 근거 상태

관찰된 사실은 사용자가 이 사업을 조직 실험의 출발점으로 선택했다는 것뿐이다. 고객 불편·수요·비용·수익에 관한 내용은 검증 대상 가설이다. 에이전트 의견의 일치는 외부 근거를 대신하지 않는다.

## 독립 검토 R1

| 검토 | 의견 | 핵심 논거 | 제안한 검증 |
| --- | --- | --- | --- |
| 고객·마케팅 | 추가 조사 | 정보량보다 날짜·거리·가격·조건 확인이 문제일 수 있다. 행사와 할인 탐색은 다른 수요다. | 한 지역 주말 행사 후보. 대상자 8명의 실제 과업 비교, 5명 이상의 반복 불편 및 2주 내 3명 이상의 자발적 재요청을 탐색 기준으로 제안 |
| 재무·투자 | 추가 조사 | 반복 이용·지불 의사·정보 갱신 비용이 미확인이다. 개발로 다른 가설 검증이 늦어질 수 있다. | 최소: 문제·공급 조사, 기준: 수동 목록, 확대: 수요·공급 검증 후 자동화. 현금과 인력 환산을 분리하고 단계별 상한 설정 |
| 기술·데이터·운영 | 추가 조사 | 갱신 지연, 중복, 조건 누락, 이용 가능성, 검수 비용이 핵심 위험이다. | 이용 조건을 확인한 출처 3곳·30항목을 7일 추적. 필수 정보 90% 이상, 변경의 다음 점검 반영, 건당 관리시간 한도 충족을 탐색 기준으로 제안 |

위 표의 표본·기간·비율은 검토자가 제안한 초기 기준이며 통계적 타당성이나 시장성을 입증하지 않는다. 출처와 참가자는 아직 확보되지 않았다.

## 사업 제안 수정 P0 v2 및 교차 반론 R2

제안자는 범용 이벤트·할인 통합 검색 구현을 보류하고, 한 지역의 주말 행사 탐색을 첫 고객 문제 후보로 선택했다. 수동 목록으로 가치와 정보 유지 비용을 검증하는 조사 설계만 우선한다. 지역은 미정이다.

- 고객·마케팅: 목록에 대한 호감은 검색 수요와 다르다. 같은 실제 과제를 기존 방식과 비교하고 실제 선택·조건 오류·자발적 재요청을 측정해야 한다. 공급 검증과 고객 검증을 분리하는 조건으로 수용했다.
- 재무: 재요청만으로 고객 획득 비용·지불 의사를 입증하지 못한다. 모집·수집·검수 시간을 기록하고 통과 후에도 다음 심의를 거치는 조건으로 수용했다.
- 기술·운영: 고객 반응이 좋아도 최신성·정확성·반복 운영 가능성이 보장되지 않는다. 이용 조건 확인 방법, 변경·취소 점검 주기, 관리시간 한도를 정하는 조건으로 수용했다.

## 의장 결정 D0 v1

입력: P0 v1, 독립 검토 R1 3건, P0 v2, 교차 반론 R2 3건.

**결과: 추가 조사. 조사 설계는 진행하되 제품 개발 투자는 보류한다.**

사업 제안의 가능성을 기각할 근거도, 개발에 투자할 근거도 아직 없다. 서로 다른 관점에서 고객 문제·공급 가능성·운영 비용이 모두 미확인으로 드러났다. 첫 고객군 후보는 한 지역의 주말 행사 탐색으로 좁히며, 이 후보도 조사 결과에 따라 변경한다. 수동 목록, 알림, 검색은 비교할 대안으로 유지한다.

반대 표결은 없었지만 조건부 수용에 붙은 반론은 열린 조건으로 보존한다. 동일 계열 모델의 의견 일치를 독립적 시장 증거로 계산하지 않는다. 의장과 제안자가 같은 주 에이전트이므로 의사결정 독립성에도 한계가 있다.

### 후속 작업과 재심 조건

| ID | 책임 역할 | 다음 산출물 | 완료 조건 |
| --- | --- | --- | --- |
| G1-01 | 고객 조사 | 후보 지역·고객군 선택 근거, 인터뷰·과업 비교 설계 | 관찰과 선호 질문 구분, 모집 경로, 탐색 지표·중단 기준 명시 |
| G1-02 | 마케팅 | 수동 목록·알림·검색의 가치 제안 비교 | 고객군별 메시지와 검증 방식 명시; 광고 집행 없음 |
| G1-03 | 데이터·운영 | 출처 후보와 이용 조건 확인 계획 | 최신성·정확성·취소·중복 점검 방법, 실제 공급 미확인 표시 |
| G1-04 | 재무 | 단계별 예산표 | 기간·인력시간·현금·모델 사용 상한 및 미확인 단가 명시 |
| G1-05 | 의장 | 조사 실행 준비 여부 재심 | G1-01~04 버전 검토, 미충족 조건 기록 |

예산 산식: `작업시간 × 환산단가 + 모델 사용량 × 단가 + 데이터·인프라·모집 비용`. 인력 환산은 현금 지출과 별도 표시한다. 실제 단가와 다음 조사 상한은 미정이며 이 결정은 지출 승인이 아니다. 현재 심의의 모델 사용 비용·토큰은 도구에서 집계받지 못했으므로 unknown이다.

고객 문제가 관찰되지 않거나, 활용 가능한 공급을 확보하지 못하거나, 유지 비용이 설정할 한도를 넘으면 방향 전환 또는 중단을 재심한다. 조사 기준 통과도 개발 자동 승인을 의미하지 않는다.

## 실행 결과와 한계

- 협업 도구로 독립 검토 에이전트 3개를 실행하고, 각각을 동일 세션에서 1회 재호출해 타 부문의 반론을 검토했다. 주 에이전트 포함 동시 에이전트 상한은 4다.
- 최초안 → 독립 검토 → 수정안 → 교차 반론 → 의장 결정의 순서를 실제로 수행했다. 검토 요약과 결정의 연결을 위에 기록했다.
- 범용 검색 구현에서 좁은 고객군의 수동 검증으로 우선순위가 바뀌었다. 이는 심의 결과이며 시장 검증 결과가 아니다.
- 40개 전문 역할 전체를 실행하지 않았다. 3개 검토 에이전트가 복수 직무를 묶어 맡았으므로 세부 역할별 컨텍스트 격리를 입증하지 않는다.
- 도구 기반 외부 조사, 영속 저장 후 프로세스 재시작, 실제 role-runtime 실행, 처리량·RSS·비용 비교는 수행하지 않았다. 이 파일럿은 의사결정 절차의 작동 예시이며 효율·품질 우위를 입증하지 않는다.
